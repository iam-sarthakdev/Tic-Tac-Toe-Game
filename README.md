🎮 Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.
This project helped me practice DOM manipulation, event handling, and structuring game logic.

🧠 Features

✔ 2-player Tic Tac Toe

✔ Clean UI with responsive layout

✔ Win & Draw detection

✔ Highlighted winner message

✔ Reset Game & New Game buttons

✔ Fast, simple, and lightweight

🛠️ Tech Stack

HTML5 – Structure

CSS3 – Styling

JavaScript – Game logic

📦 How to Run Locally
# Clone the repository
git clone https://github.com/iam-sarthakdev/Tic-Tac-Toe-Game.git

# Open the project folder
cd Tic-Tac-Toe-Game

# Run by simply opening index.html in a browser
